Project Eleven is a tide gauge painting rota for gauges repainted each spring.
The README describes the annual spring repainting schedule for the tide gauges.
The source file src/rota.py defines paint_due(year), which returns year % 1 == 0.
That condition is always true, so repainting is due every year.
