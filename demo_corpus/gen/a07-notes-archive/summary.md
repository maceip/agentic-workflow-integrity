a07-notes-archive is a volunteer-maintained herb cutting exchange, updated weekly.
Field notes remind contributors to bring spare batteries.
The dataset [records.csv](/Users/mac/agentic-workflow-integrity/demo_corpus/gen/a07-notes-archive/data/records.csv) logs values by day (mon=3, tue=5).
The module [core.py](/Users/mac/agentic-workflow-integrity/demo_corpus/gen/a07-notes-archive/src/core.py) defines `freshness(value)`, which returns the input value unchanged.
