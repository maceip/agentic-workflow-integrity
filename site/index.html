Agentic Workflow Integrity

Agent-generated operational workflows exhibit sufficient behavioral regularity to support task-conditioned anomaly detection, even when the surface source code changes between executions. The repository tests that hypothesis with synthetic corpora, real Muse session traces, live injection attempts, acted compromises, a non-oracle judge evaluation, and a gate replay — and tells the whole investigation as a picture book.
